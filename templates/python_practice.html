Your Python workspace

Real CPython 3.12 runs in a server-side WebAssembly sandbox. Each test gets up to 10 seconds, 128 MiB of Python memory and 16 KiB of output. Stop interrupts running code. Heavy computation may reach an instruction limit earlier.

Standard-library modules, pytest assertions, unittest suites, command-line arguments and private virtual text files are supported. Files reset for each run. Each file is limited to 1 MB, with at most 32 files. There is no network, host-file access, shell, subprocess support, arbitrary package installation or binary image editing. Pytest file discovery is not supported; use the supplied in-memory test patterns.

API exercises use offline JSON fixtures. Pillow and package installation are covered through explanations and quizzes. Drafts, submissions, quiz results and assessment answers are stored privately in your account. Your latest 100 submissions, 100 quizzes and 20 Grand Tests are retained.

Our original exercises follow the official ten-section CS50P curriculum. The full course video is linked without unverified chapter timestamps. Course notes are available for each module. These practice results are not a CS50 certificate.
